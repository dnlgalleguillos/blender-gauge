# Changelog

## 0.1.0
First release. Written from scratch.
- `lib/gauge.py`: reports with value / limit / hint, parameter handling, mesh and scene measurements, camera framing, image statistics and comparison, node-tree dump / build / text, Geometry Nodes helpers (`gn_make`, `gn_set`, `instance_count`), isolated workspaces.
- Eight skills: `gauge-core`, `gauge-scene`, `gauge-modeling`, `gauge-materials`, `gauge-geonodes`, `gauge-light-render`, `gauge-reference`, `gauge-export`.
- Gallery of renders produced by the skills' own scripts, each with its gate results (`assets/gallery/gates.json`).
- Tooling: `tools/check_repo.py`, `tools/run_tests.py`, `tools/sync_lib.py`, `tools/install.py`.
